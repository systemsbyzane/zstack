# Recover

For the Coordinator. Diagnose the concrete failure, preserve useful state, and
repair setup, commands, configuration, or code within the existing assignment
authority. Keep the same owner for connected runtime work. Retry only after a
meaningful correction; record the failure and rerun affected verification.

If the same approach fails again, change the method or capability; reconsider
the assigned worker's suitability and use an available peer when useful. Send a
meaningful correction back to the current worker when continuity is useful and
cancel obsolete competing runs. There is no fixed retry budget. Follow
`skills/cortex/references/model-routing.md` for fallback and dispatch receipts.
Escalate only for a genuine missing decision, authority, authentication, or
blocker with no viable authorized path. Do not poll, create watchdogs, or ask
for routine approval. Preserve failed outcomes, rerun affected checks, then
generate a new execution receipt on the final clean revision with `/prove-it`.
