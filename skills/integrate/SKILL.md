# Integrate

For the Coordinator. Confirm ownership and exact source revisions, integrate
returned work, resolve conflicts, and inspect the combined diff. Run focused
checks through the actual production path, fix evidenced defects, and rerun
affected checks. Preserve failed outcomes and report what did not run.

Finish with `/prove-it`. Integration is not complete because workers finished
or individual changes passed in isolation. Follow the evidence contract in
`skills/cortex-coordinator/references/evidence.md`.
