# Cortex status reporting v1

Read this contract for material coordinator events and chief status projection updates.

Coordinators include `reportedAt` (actual event UTC ISO 8601 ending Z), stable `assignmentId`, `status` (needs-you, blocked, ready-for-review, working, done, unknown), concise `phase` and one-sentence `summary`, `blocker` and `decisionNeeded` (string or null), canonical tool-returned `coordinatorLink`, and `testedRevision` (string or null). Keep existing eventId/kind/checks/evidence fields. Do not invent event times, identities or runtime status. Unknown canonical identity must be reported as unknown; chief maps against its trusted roster. Report material progress only, no polling or repetitive acknowledgments. Coordinators never write chief state or projection. Reporting updates do not restart work or expand authority. Chief verifies adoption from a compliant real report or one explicitly requested bounded acknowledgment, never a send receipt.

Chief is sole writer of state.json and an atomic sanitized status.json plus status.schema.json in the chief directory. Projection v1 fields: schemaVersion=1, generatedAt UTC ISO, chief={link}, assignments=[{assignmentId,title,status,phase,summary,lastReportedAt,coordinatorLink,blocker,decisionNeeded,testedRevision,reviewState}]. Nullable fields: lastReportedAt, coordinatorLink, blocker, decisionNeeded, testedRevision. reviewState is not-requested, pending, handled. No raw prompts, authority envelopes, credentials, evidence contents, internal paths or arbitrary state fields in projection. Preserve roster/history and exact trusted links. Update projection after material accepted events or explicit user decisions; generation time is not event time. Legacy event time stays null unless exact trusted message metadata establishes it; preserve source provenance in private state. Deduplicate eventId and ignore stale events for current display.

Ready for review stays pending until explicit user review; reading a report or board never handles review. New revision may supersede earlier evidence but cannot silently dismiss pending review. Display last-reported state, unknown timestamps and stale indicators (threshold disclosed); file reads do not establish live execution. Viewing/refreshing is read-only and never dispatches agents, approves actions, calls model/agent APIs, or mutates chief state. Board serves only fixed sanitized projection through an allowlisted read-only loopback endpoint, no arbitrary paths or raw state. Done is collapsed by default.
