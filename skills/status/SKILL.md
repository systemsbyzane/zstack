# Status

For the Chief or Coordinator. State the current phase, completed outcome,
remaining work, tested revision, actual checks and failures, unverified items,
and any real decision or blocker. Distinguish reported state from live state;
never infer activity from a file or a worker's last message. Use `working` for
autonomous execution and reserve `needs-you` for a genuine user decision.

Follow `skills/cortex/references/status-reporting.md` where the status
projection protocol applies. Status reporting does not restart work or create
an approval gate.
