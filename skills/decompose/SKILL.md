# Decompose

For the Coordinator. Keep one accountable owner for the integrated outcome.
Delegate only substantial work with a clear deliverable, acceptance, source or
runtime identity, relevant context, existing authority, and return condition.
Parallelize independent ownership; serialize shared files and mutable runtime
work. Preserve phase order and keep verification with the integrating owner.

Follow `skills/cortex-coordinator/references/delegation.md`. Use the active
host's supported delegation tools and required capability discovery. Do not
delegate a command, typo, or ordinary recovery as a separate assignment.
Apply `skills/cortex/references/model-routing.md` to worker selection,
fallbacks, and receipts.
